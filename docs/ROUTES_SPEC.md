# ROUTES_SPEC.md

Guren has no separate API layer: controllers return Inertia pages (props typed to React) or redirects. JSON is used only where noted. Register routes in `routes/web.ts` (private) and `routes/public.ts` (public), name every route, and verify against `bunx guren graph`.

Legend: 🌐 public · 🔒 requires login (inside the `auth` group) · **P** Inertia page · **R** redirect back (Inertia form) · **J** JSON.

## 3. Pages (all 🔒 **P**)

Common query params: `sort` = `name` \| `modified` \| `size` (default `name`), `order` = `asc` \| `desc`, `view` = `grid` \| `list` (also stored client-side).

| Path | Name | Props |
|---|---|---|
| `/` | `home` | redirect → `/files` |
| `/files` and `/files/:folderId` | `drive.index` | `{ folder, breadcrumbs, folders, images }` |
| `/recent` | `drive.recent` | `{ images }` (last 100 by `created_at`, grouped by day in the UI) |
| `/starred` | `drive.starred` | `{ folders, images }` |
| `/trash` | `drive.trash` | `{ folders, images }` (items whose parent is not itself trashed) |
| `/search?q=` | `drive.search` | `{ q, folders, images }` (name contains, case-insensitive, limit 200) |

**Shared props** on every private page (via `shareInertiaProps`):
```ts
{
  auth: { user: { id, name, email } },
  capabilities: { webp: boolean, avif: boolean, maxUploadMb: number, defaults: { format: 'webp'|'avif'|'original', qualityWebp: number, qualityAvif: number } },
  storage: { usedBytes: number, imageCount: number },
  publicBaseUrl: string,
  flash: { success?: string, error?: string },
}
```

**Resource shapes**
```ts
type ImageItem = {
  id: number; publicId: string; name: string; folderId: number | null;
  starred: boolean; version: number; format: 'avif'|'webp'|'jpeg'|'png'|'gif';
  mime: string; size: number; width: number; height: number;
  createdAt: number; updatedAt: number; deletedAt: number | null;
  urls: { thumb: string; permanent: string; latest: string; page: string }; // absolute via UrlBuilder
  versions?: { version: number; format: string; size: number; createdAt: number; isCurrent: boolean; permanent: string }[]; // details panel only
};
type FolderItem = { id: number; parentId: number | null; name: string; starred?: never; createdAt: number; updatedAt: number; deletedAt: number | null };
type Crumb = { id: number | null; name: string };   // id null = "My Files"
```
Folders have no star in v1 (images only), keep the type narrow.

## 4. Mutations (all 🔒)

### Folders
| Method | Path | Name | Body | Result |
|---|---|---|---|---|
| POST | `/folders` | `folders.store` | `{ name, parentId? }` | **R** |
| PATCH | `/folders/:id` | `folders.update` | `{ name?, parentId? }` | **R** |

Rules: name 1 to 255 chars, trimmed, no `/` or `\`. Create and move auto-suffix ` (1)` on a clash. Explicit rename onto an existing name → validation error. Moving into itself or a descendant → validation error `CYCLE` (400/422).

### Images
| Method | Path | Name | Body | Result |
|---|---|---|---|---|
| POST | `/uploads` | `uploads.store` | multipart: `file`, `format`, `quality?`, `maxDimension?`, `folderId?`, `name?` | **J** 201 `{ image, originalSize, storedSize, savedBytes, savedPercent }` |
| POST | `/images/:id/versions` | `images.replace` | multipart: `file`, `format`, `quality?`, `maxDimension?` | **J** 201 `{ image, originalSize, storedSize, savedBytes, savedPercent }` |
| POST | `/images/:id/versions/:version/restore` | `images.restoreVersion` | none | **R** (moves `current_version`) |
| PATCH | `/images/:id` | `images.update` | `{ name?, folderId?, starred? }` | **R** |

- Upload errors (Guren's standard shapes): `413` too large, `415` unsupported type, `422` validation (bad option, unavailable format, pixel cap, AVIF on animated input), `503` storage unavailable. The UI shows `message` per file with a Retry.
- Renaming an image updates `name` and `slug`; it does **not** bump the version.
- Replace requires the image to be active (not trashed).

### Bulk (body `{ imageIds: number[], folderIds: number[] }`, max 500 total)
| Method | Path | Name | Extra | Result |
|---|---|---|---|---|
| POST | `/items/move` | `items.move` | `targetFolderId: number \| null` | **R** (atomic; whole request rejected on `CYCLE`) |
| POST | `/items/star` | `items.star` | `starred: boolean` (images only) | **R** |
| POST | `/items/trash` | `items.trash` | | **R** |
| POST | `/items/restore` | `items.restore` | | **R** |
| POST | `/items/delete` | `items.delete` | | **R** permanent; only items already in trash; deletes all versions' objects, then rows |
| DELETE | `/trash` | `trash.empty` | | **R** permanent delete of everything in trash |

Permanent deletes: objects first, then rows. On storage failure keep rows and return an error flash.

## 5. Middleware and cookies

- Private routes: session + CSRF (Guren `auth: {}`) + `auth` alias (`requireAuthenticated({ redirectTo: '/login' })`).
- Public image routes (`/i`, `/t`) must not issue `Set-Cookie`. If the global session/CSRF middleware attaches cookies to GETs, exclude these prefixes or register the routes outside it (task 1.3 settles the mechanism and records it in the decision log).
  - Settled in 1.3: `createApp` runs with `autoSession: false, autoCsrf: false`, and `app/Providers/SessionCsrfProvider.ts` mounts the same session/CSRF middleware for every path except the `/i/`, `/t/`, `/p/` prefixes, which skip both entirely (the framework's CSRF middleware sets `XSRF-TOKEN` on every safe request and its session middleware re-issues the session cookie; `csrfOptions.exclude` cannot prevent either). `GET /health`, `/login` and `/logout` are unaffected.
- The upload endpoints accept the CSRF token via the `X-XSRF-TOKEN` header (cookie `XSRF-TOKEN`).
- Rate limiting (task 5.2): public routes get a generous per-IP limit; `POST /uploads` and `/images/:id/versions` a modest one.

## 6. Route-guard sweep

`tests/route-guard.test.ts` iterates every registered route that is not `GET`/`HEAD` and asserts an unauthenticated request is not 2xx. It also asserts the public allowlist in §1 is exactly the set of routes reachable without login.
